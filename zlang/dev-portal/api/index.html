API pubbliche

Le interfacce dell’ecosistema che oggi rispondono davvero a chiunque. Gli altri servizi hanno API interne o protette e non sono elencati qui.

Directory dei servizi · ecosystem.json

GET https://x-zdos.it/ecosystem.json — elenco dei servizi del portale con URL e maturità (live, demo, beta…).

curl -s https://x-zdos.it/ecosystem.json

Verifica holder del bot Discord

Usata dalla pagina /discord/verify/ dopo il comando /verifica su Discord. Limite: 30 richieste al minuto per IP.

MetodoPercorsoCosa fa
GET/discord/api/healthStato del servizio: {"ok":true,"discord":true,…}
GET/discord/api/message?n=<nonce>Messaggio da firmare per un nonce emesso da /verifica, con scadenza.
POST/discord/api/verifyCorpo JSON {nonce, publicKey, signature}: verifica la firma ed25519 del messaggio. Non muove fondi.
curl -s https://x-zdos.it/discord/api/health

RPC pubblici usati da IDE e portale

ReteEndpointNote
Solana mainnethttps://solana-rpc.publicnode.comFunziona dal browser. Le chiamate indicizzate (getProgramAccounts, getTokenAccountsByOwner, getTokenAccountBalance) richiedono un token: per i saldi l’IDE calcola il conto associato e usa getAccountInfo.
Solana mainnethttps://api.mainnet-beta.solana.comRifiuta le chiamate dai browser (403); va bene da server o da terminale.
Solana devnethttps://api.devnet.solana.comIl faucet via RPC è chiuso: SOL di test da faucet.solana.com.
Polygon PoShttps://polygon-bor-rpc.publicnode.comRiserva: https://polygon.drpc.org.

Nell’IDE puoi impostare un tuo endpoint Solana nel pannello zcomm; resta salvato solo nel tuo browser.

Host dell’IDE (namespace chain/)

Non è un’API HTTP: è il modo in cui un programma Zlang chiede dati on-chain all’IDE con storage.read. Percorsi e risposte sono nella guida al linguaggio.

Cosa non è un’API pubblica

  • Lo swap zRoute usa le API di Jupiter direttamente dal browser: non c’è un’API zRoute da chiamare.
  • zdesk, il Radar e i servizi di OurVelvet hanno API interne, protette o legate al sito 18+: non sono documentate qui.
