Esempi

Sono gli stessi modelli dell’IDE. “Apri nell’IDE” li carica in un file nel tuo browser; la compilazione e l’esecuzione restano locali. Le letture chain/ sono in sola lettura.

Hello Zlang

Il primo programma: due righe emit. Gira su entrambi i toolchain.

# Esempio da zlang/examples/hello.zlang
emit Ciao dal programma Zlang nativo
emit Il kernel ZDOS ha eseguito questo bytecode

Tutte le istruzioni ZLB2

Etichette, if … jump, wait e storage.read compilati da zlangc.

# Tutte le istruzioni di zlangc v2.5 (bytecode ZLB2)
emit Avvio nodo
let tentativi = 3
loop:
storage.read "config/nodo.json"
wait
if tentativi == 0 jump fine
let tentativi = tentativi - 1
fine:
emit Fine

zNFT · regole di certificazione

Il programma che la galleria zNFT esegue prima della revisione: hash, dichiarazioni 18+, consensi, segnalazioni. Namespace znft/.

zlangc v2.5: 837 byte di bytecode ZLB2, 29 istruzioni.

# Regole zNFT v1 (certificazione) · ZDOS1.3 · eseguite dal server prima della revisione e del mint (devnet)
# I valori arrivano dal namespace znft/ (host regole zNFT, sola lettura). Esito: emit OK oppure BLOCCO:<motivo>
storage.read "znft/opera/hash_ok"
storage.read "znft/opera/persone_ritratte"
storage.read "znft/opera/consensi_validi"
storage.read "znft/artista/maggiorenne_dichiarato"
storage.read "znft/artista/diritti_dichiarati"
storage.read "znft/opera/segnalazioni_aperte"
let sempre = 1
if hash_ok != 1 jump no_hash
if maggiorenne_dichiarato != 1 jump no_eta
if diritti_dichiarati != 1 jump no_diritti
if consensi_validi < persone_ritratte jump no_consenso
if segnalazioni_aperte > 0 jump segnalata
emit "OK"
if sempre == 1 jump fine
no_hash:
emit "BLOCCO:hash SHA-256 mancante o non valido"
if sempre == 1 jump fine
no_eta:
emit "BLOCCO:manca la dichiarazione 18+ dell'artista"
if sempre == 1 jump fine
no_diritti:
emit "BLOCCO:manca la dichiarazione sui diritti dell'opera"
if sempre == 1 jump fine
no_consenso:
emit "BLOCCO:mancano consensi firmati dei modelli"
if sempre == 1 jump fine
segnalata:
emit "BLOCCO:opera con segnalazioni aperte"
fine:
